# 🍎 Aplicação Educacional e Lúdica: Educação Alimentar

Este projeto consiste numa aplicação interativa desenvolvida para crianças em idade escolar (ensino primário).O objetivo principal é ensinar conceitos fundamentais de nutrição saudável e educação alimentar de forma divertida e cativante.

Projeto desenvolvido no âmbito da Unidade Curricular de **Conteúdos Interativos**, no 2.º Ano (2.º Semestre) do ano letivo 2025/2026

## ✨ Características Principais

A aplicação foi desenhada para captar a atenção do público infantil através de personagens e metáforas visuais, incluindo as seguintes características:

**Atividades Duplas:** Cada atividade contém uma componente de aprendizagem teórica e uma componente lúdica (minijogo).
**Dificuldade Progressiva:** Todos os minijogos incluem pelo menos três níveis de dificuldade.
**Navegação Intuitiva:** Estrutura não-linear com, no mínimo, três níveis hierárquicos de menus e instruções claras em cada ecrã.
**Multimédia Integrada:** Utilização combinada de texto, imagem, animação, som e vídeo.
**Temas Abordados:** Grupos alimentares, importância das cores dos alimentos, distinção entre alimentos nutritivos e ocasionais, e a importância de beber água.

## 🛠️ Tecnologias Utilizadas
